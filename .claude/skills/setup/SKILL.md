Fetch the guide raw and follow it from the top, step by step:

```bash
curl -fsSL https://raw.githubusercontent.com/dominic676767/meeting-summarizer/main/docs/guide/installation.md
```

If the network is not available, read `docs/guide/installation.md` in this clone instead. The guide on `main` is the single source of truth: do not follow a summary of it, and do not skip its rules.

For an update or a check of an existing clone, start at the guide's "Updating" section, then run `npm run doctor`.
